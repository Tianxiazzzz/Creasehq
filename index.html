      Common questions

      Is there a file size or page limit?

      No artificial limit is set by this tool. Very large files depend on your device's available memory, since processing happens in your browser.

      Do you store my documents?

      No. Files are processed locally in your browser and are never uploaded anywhere.

      Can I reorder pages before merging?

      Yes — use the up and down controls next to each file in the list to change the order before you merge.

      Will compressing my PDF keep the text selectable?

      No — compression re-renders each page as an image, so the resulting file is a lightweight picture of each page rather than searchable text. Use it for scans or photo-heavy PDFs, not documents you need to keep text-selectable.

      What Word file formats can I convert?

      Modern .docx files. Older .doc files aren't supported directly — open them in Word and save as .docx first.

      Will PDF to Word keep my original layout?

      No — this pulls out the text and rebuilds it as a plain, editable Word document. Formatting, tables, columns, and images aren't preserved, and scanned PDFs with no real text layer won't produce any text at all.
